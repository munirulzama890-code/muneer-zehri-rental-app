Muneer Zehri Rental App — موبائل پر انسٹال کرنے کا طریقہ

اہم: یہ APK نہیں بلکہ انسٹال ہونے والی ویب ایپ (PWA) ہے۔ اسے ایک مرتبہ انٹرنیٹ کے ذریعے HTTPS ویب سائٹ پر اپ لوڈ کرنا ضروری ہے۔ پھر Chrome سے انسٹال کریں، اور بعد میں ایپ آف لائن بھی کھل سکتی ہے۔

GitHub Pages:
1) ZIP کو extract کریں۔
2) اس فولڈر کے اندر موجود تمام فائلیں اور icons فولڈر اپنی GitHub repository کے ROOT میں upload کریں۔
3) index.html لازماً root میں ہونا چاہیے۔
4) GitHub repository میں Settings > Pages کھولیں۔
5) Deploy from a branch منتخب کریں، Branch: main، Folder: /(root)، پھر Save کریں۔
6) GitHub کی بنائی ہوئی https://...github.io/... ویب سائٹ Chrome میں کھولیں۔
7) Chrome کے تین نقطوں (⋮) سے Install app یا Add to Home screen منتخب کریں۔
8) ایپ ایک بار آن لائن کھولنے کے بعد دوبارہ آف لائن چلنے کے لیے تیار ہو جائے گی۔

احتیاط:
- اپنا ڈیٹا محفوظ رکھنے کے لیے وقتاً فوقتاً ایپ کے اندر Backup بنائیں۔
- Browser کا data/cache صاف کرنے یا دوسری ویب سائٹ/لنک سے کھولنے پر مقامی ریکارڈ ضائع یا الگ ہو سکتا ہے۔
- Cloud sync، خودکار email sync اور native Android APK اس پیکیج میں شامل نہیں۔
- موجودہ سافٹ ویئر کی تمام خصوصیات کی مکمل عملی جانچ اس پیکیج کے ساتھ نہیں کی گئی۔
